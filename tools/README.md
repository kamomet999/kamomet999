# hp_ftp.py — ISP ホームページ領域の バックアップ / 削除 ツール

Hit net TV! (hidatakayama.ne.jp) などの ISP ホームページ領域を、
**必ずバックアップを取ってから**消すための道具。Python 3.9+ の標準ライブラリのみで動く。

## 使い方（この順番で）

```bash
# 1. まず中身を見る（何も変更しない）
python3 hp_ftp.py list --host <FTPサーバー名> --user <ユーザー名>

# 2. 全ファイルをローカルに保存（何も変更しない）
python3 hp_ftp.py backup --host <FTPサーバー名> --user <ユーザー名> --dest ./hp-backup

# 3. 消える対象を確認（何も変更しない）
python3 hp_ftp.py wipe --host <FTPサーバー名> --user <ユーザー名> --backup ./hp-backup --dry-run

# 4. 本当に削除（DELETE と手入力しない限り実行されない）
python3 hp_ftp.py wipe --host <FTPサーバー名> --user <ユーザー名> --backup ./hp-backup
```

パスワードは実行時にプロンプトで聞かれる（画面に表示されず、履歴にも残らない）。

## FTP サーバー名・ユーザー名はどこに書いてある？

加入時に ISP から郵送された **「登録内容通知書」** に記載。
見つからなければ Hit net TV! お客様サービスセンター **0800-200-8688**（9:00–18:00）へ。
ホームページの FTP ユーザー名はアカウント ID（例: cb10377）と同じことが多い。

## 安全装置

`wipe` は次の場合すべて**削除せずに中止**する:

- バックアップの目録 (`manifest.json`) が無い
- バックアップにファイルの欠損がある
- バックアップ後にサーバー側へ新しいファイルが増えている
- サーバー側の一覧に解釈できない行がある（取りこぼしの疑い）
- 確認プロンプトで `DELETE` と正確に入力されなかった

`backup` はファイルが 0 個のとき目録を書かずに失敗する
（空の目録を根拠に wipe が通るのを防ぐため）。

## 対応している古いサーバー

- ファイル名が Shift_JIS の領域（自動判定。化ける場合は `--encoding cp932`）
- MLSD 非対応（Unix / DOS 形式の LIST に自動フォールバック)
- FTPS が使えるなら `--tls` を付ける（平文 FTP しか無い ISP も多い）

## 注意

- ホームページ領域を消してもメール容量 (50MB) は 1 バイトも増えない（別枠）
- 領域ごと廃止するにはポータルの「ホームページアドレス登録/変更」で
  「利用しない」に変更する（ファイル削除だけでは URL の枠が残る）
- 検索結果や Internet Archive のキャッシュはサーバーを消しても残る
