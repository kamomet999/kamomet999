# tools/netcheck.sh

手元のマシンのネットワーク環境を実測して、**どこがボトルネックなのか**と
**何をすれば速くなるのか**を効果の大きい順に出すスクリプトです。

```bash
bash tools/netcheck.sh
```

インストールは不要です (macOS / Linux、標準コマンドと python3 のみ使用)。

## 何を見ているか

| # | 項目 | 判定できること |
|---|------|----------------|
| 1 | デフォルトルート | **ルーター経由かどうか**、テザリング (CGNAT)、ONU 直結、VPN、二重 NAT |
| 2 | Wi-Fi | 2.4GHz か 5GHz 以上か、規格 (11n/ac/ax/be)、電波強度、リンク速度 |
| 3 | ping | ルーターまで / インターネットまでの遅延とパケットロス |
| 4 | DNS | 現在の DNS と 1.1.1.1 / 8.8.8.8 / 9.9.9.9 の応答速度比較 |
| 5 | スループット | 下り・上り速度と応答性 (RPM) — バッファブロートの検出 |
| 6 | まとめ | 上記から導いた具体的な対処を、効果の大きい順に列挙 |

## ポイント

**ルーターまでの ping と、インターネットまでの ping を分けて測っている**のが肝です。
ここが切り分けの要になります。

- ルーターまでが遅い → 原因は**宅内の Wi-Fi**。回線を変えても直りません。
- ルーターまでは速いのに外が遅い → 原因は**回線・ISP 側**。Wi-Fi をいじっても無駄です。

## オプション

```bash
bash tools/netcheck.sh --no-public   # グローバル IP の外部確認をしない (二重 NAT 判定は省略)
```

`--no-public` を付けない場合、二重 NAT を判定するために `api.ipify.org` に
1 回だけアクセスします。それ以外に外部へ送信するものはありません。
